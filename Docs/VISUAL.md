# LIST — VISUAL DIRECTION

## Visual Identity

LIST aims for grounded photorealism with cinematic horror presentation and a deliberately imperfect sense of reality.

The environment should feel believable before it feels supernatural.

## Historical Atmosphere

The 1998-inspired East Java setting should feel lived-in and historically grounded.

Environmental storytelling can use:

- Photographs
- Handwriting
- Documents
- Stains
- Moved/missing objects
- Reflections
- Distant changes
- Period-appropriate architecture and objects

## Imperfection

A previously accepted visual direction is:

**Realistic world captured through imperfect low-fidelity footage when the fiction calls for it.**

Possible visual languages:

- Bodycam
- CCTV
- VHS
- Consumer camera footage

Possible artifacts:

- Compression
- VHS noise
- Chromatic aberration
- Rough motion blur
- Exposure/white-balance shifts
- Blown highlights
- Autofocus hunting
- Lens distortion
- Sensor grain
- Imperfect audio

Use this sparingly. A previous target was roughly **90% ordinary footage / 10% subtly wrong phenomena**, as a design guideline rather than a technical ratio.

## Visual Philosophy

The horror should not be constantly visible.

The player should first notice something is wrong, then question whether they actually saw it.
