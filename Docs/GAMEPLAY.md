# LIST — GAMEPLAY

## Core Experience

LIST is a first-person exploration/investigation horror game.

Primary loop:

**Explore → Observe → Interact → Find evidence → Interpret → Follow the mystery → Encounter anomaly → Continue investigating**

## Player Actions

The current gameplay direction emphasizes:

- Walking/exploration
- Observation
- Interaction
- Inspection
- Hiding
- Using a camera/story evidence
- Environmental investigation

## Combat

**No combat is the intended direction.**

LIST should not become a conventional FPS with weapons, enemy encounters, or combat progression.

## Horror Interaction

The player should often be uncertain whether something has changed.

Horror can emerge from:

- Something appearing where it should not be
- Missing or moved objects
- Reflections
- Distant changes
- Audio anomalies
- Documentation that contradicts reality
- Observation itself becoming dangerous

## Cinematics

Use cinematics sparingly.

The first-person player experience should remain dominant. Cinematic moments should establish or reinforce information, not replace gameplay.

## Design Target

The player should feel:

**"Aku harus tahu apa yang sebenarnya terjadi."**

rather than:

**"Aku harus membunuh monster ini."**

## Unresolved

- Exact interaction framework
- Camera mechanics
- Hiding rules
- Save/checkpoint rules
- Exact threat encounter loop
